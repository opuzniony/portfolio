Currently reading

Trying to understand how computers work

CODE: The Hidden Language of Computer Hardware and Software

by Charles Petzold

I want to fully understand computers and their inner workings, that's why I chose this book as the first one I will be reading about computers, It starts from things like flashlights and Morse code and works its way up to how a CPU actually runs, not "how to program," but what a computer actually is from a logic gate standpoint.

And after that?

Building a computer from scratch ( hopefully )

The Elements of Computing Systems, Second Edition: Building a Modern Computer from First Principles

by Noam Nisan and Shimon Schocken

Better known as Nand to Tetris, building an actual computer starting from a single NAND gate, up through logic gates, memory, a CPU, an assembler, a compiler, and eventually running a real program on the thing. Then probably something after that too.
